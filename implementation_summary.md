# Implementation summary

The solution uses Python and the OpenAI SDK. `llm_judge_evaluation.py` loads five fictional, evidence-backed company-research cases from `test_cases.json`, renders the prompts, applies clear deterministic validation and, in **live** mode, sends each candidate answer to an LLM judge. The judge receives the original task, supplied evidence, a hand-authored reference answer and the candidate response. It returns structured JSON with a 1–5 score, brief factual explanation and four binary criteria. The script validates this JSON, preserves per-case answers and records candidate/judge token usage, model latency and estimated API cost. `fixture_responses.json` intentionally includes both sound and flawed responses for reproducible negative controls.

The executed **offline** run is saved in `evaluation_results.json`: three of five handcrafted examples passed the literal rule checks. Two known-bad samples failed: the arithmetic error in TC03 and the prompt-injection compliance error in TC05. This proves only that the local constraints detected those particular errors; it does not prove anything about a generated model's accuracy or an LLM judge's agreement with experts. Judge metrics and model costs are null in this result file because no API key or authorized OpenAI request was available in the preparation environment. The static-rule processing time is not API/model latency.

Next, install the dependencies, set a private API key, and run `python3 llm_judge_evaluation.py --mode live --candidate-source generated`. This will save genuine model and judge responses to `evaluation_results_live.json`, and an automatic reviewer-readable `live_run_summary.md`; review the score reasoning and export a one-page memo update from those results before submitting. Follow with independent human labels and repeated runs of cases where wrong company identity, arithmetic, hallucinated ownership or malicious source text could create consequential errors. Pricing is only an estimate based on configured USD/token rates, not a provider bill or environmental footprint.
