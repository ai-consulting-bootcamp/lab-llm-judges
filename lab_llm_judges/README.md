**Author:** Kimia Asgari  
**Scenario:** Retail Customer Service Chatbot (Option C)  

## Chosen Scenario

A mid-size online retailer wants to deploy an LLM-powered customer service chatbot to handle returns, product questions, order tracking, and complaint resolution. The chatbot must respond accurately, empathetically, and in compliance with company policy. Key concerns include hallucinated return policies, incorrect order information, dismissive tone under customer pressure, and failure to follow structured response formats.

## Approach Overview

1. **Benchmark Audit** — Evaluated three public benchmarks (MT-Bench, IFEval, MMLU) for relevance to the retail chatbot scenario. All three were rejected or marked for adaptation due to contamination risk, saturation, or domain mismatch.
2. **Custom Evaluation Design** — Created five evaluation prompts covering the most critical customer service interaction types, each with defined ground truth and verification strategy. Designed a full LLM-as-judge prompt with bias analysis and calibration strategy.
3. **Evaluation Memo** — Wrote a professional client-facing memo presenting (simulated) results comparing GPT-4o and GPT-4o-mini, with appropriate caveats and cost analysis.
4. **Reflection** — Addressed challenges of multilingual evaluation, the "AGI" question, and the limits of automated evaluation.
5. **Implementation** — Built a Python pipeline that generates chatbot responses and evaluates them with an LLM judge, collecting scores, timing, token usage, and cost metrics.

## How to Run the Code

```bash
# 1. Install dependencies
pip install openai python-dotenv

# 2. Set up your API key
echo "OPENAI_API_KEY=your_key_here" > .env

# 3. Run the evaluation
python llm_judge_evaluation.py
```

Results are saved to `evaluation_results.json` and a summary is printed to the terminal. Estimated cost: < $0.01 per run with GPT-4o-mini.
