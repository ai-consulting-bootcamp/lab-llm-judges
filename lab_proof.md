# LAB Proof – LLMs Grading LLMs with Receipts

**Project:** AI Food Concierge – LLM-as-Judge Evaluation  
**Date:** November 20, 2026  
**Status:** Implemented and executed

## 1. Project Overview

This lab implements a Python-based LLM evaluation pipeline for an AI Food Concierge use case. The goal is to evaluate whether an LLM can provide accurate, factually consistent, and clearly explained restaurant recommendations.

The evaluation uses a controlled synthetic dataset, predefined candidate responses, and GPT-4o-mini as an automated judge. It does not evaluate the production performance of the existing n8n prototype.

## 2. Implementation Evidence

**Implementation:** [llm_judge_evaluation.py](./llm_judge_evaluation.py)

**Evaluation results:** [evaluation_results.json](./evaluation_results.json)

**Implementation summary:** [implementation_summary.md](./implementation_summary.md)

The Python implementation:

- Sends candidate responses and ground truth to the OpenAI API.
- Evaluates three criteria: task accuracy, factual consistency, and explanation quality.
- Returns structured JSON containing scores, reasoning, and criterion assessments.
- Records execution time, token usage, and estimated API costs.
- Saves individual results and aggregate statistics.

The evaluation was executed locally using Python and the OpenAI API.

## 4. Example Test Case – Input and Evidence

**Test Case:** TC-02 – Hallucination Prevention

**Original Prompt:**

Does Trattoria Verde offer gluten-free pasta?

Available data: Italian cuisine, €24 per person, vegan options available. Gluten-free options are not specified. Do not invent information.

**Candidate Model Response (pre-written):**

"Yes, Trattoria Verde offers gluten-free pasta."

**Ground Truth:**

Gluten-free pasta availability is unknown. The response must acknowledge missing information.

**Actual Judge Output:**

Score: 1/5

Reasoning:

"The response incorrectly states that gluten-free pasta is offered, despite the available data indicating that gluten-free options are not specified. This is a major factual error."

**Interpretation:**

The judge correctly identified the unsupported factual claim. The intentionally incorrect candidate response received the lowest score, consistent with the evaluation rubric.

## 6. Failure Case and Limitations

**Observed failure case:**

TC-02 contains an intentionally hallucinated restaurant claim. The candidate response confirms the availability of gluten-free pasta despite the absence of supporting information. The judge successfully identified this error.

**Evaluation limitations:**

- Only three synthetic test cases were evaluated.
- Candidate responses were pre-written rather than independently generated by a target LLM during the evaluation run.
- The existing n8n Food Concierge workflow was not tested.
- The evaluation was performed once, without repeated runs or a formal human calibration study.
- Judge scores may vary between runs and cannot establish general model reliability.
- API costs were estimated from recorded token usage.

The evaluation therefore demonstrates a functioning LLM-as-Judge pipeline, not production readiness or general accuracy of the AI Food Concierge.
